# 本地密匣

本地密匣是一个离线使用的 Windows 加密文本管理应用，用来集中保存密码、密钥、授权码和配置说明，方便随时查找、编辑和手动复制。

每个条目只有**标题和多行正文**。标题直接显示，正文由主密码保护；解锁后，就像编辑普通文本一样使用。换电脑时，可以导出加密文件，再在另一台电脑导入合并。

## 核心功能

- **简单记录**：新增、编辑、删除条目，按标题搜索。
- **自由编辑**：正文支持换行、空格和普通复制粘贴。
- **本地加密**：主密码解锁，支持手动锁定、闲置自动锁定和修改主密码。
- **手动同步**：导出全部或勾选的条目，导入时去重并处理冲突。
- **备份恢复**：保存完整备份，在需要时恢复整个保险库。

程序在本地离线运行，数据保存在自己的电脑上。本轮修复目标、验收状态和修复记录见 [GOAL.md](GOAL.md)。

## 安装

从 [GitHub 发布版本](https://github.com/YimingHao-Github/local-vault/releases/latest) 下载最新的 Windows 安装包，安装后从开始菜单打开“本地密匣”。

支持 Windows 10、Windows 11 的 64 位系统，默认按当前用户安装，包含运行环境，无需安装 Python。当前正式版本为 `1.0.1`。首次打开时设置并确认主密码，使用至少 16 个字符的长口令，避免常见弱密码；上限为 1024 个字符，不强制字符组合。

## 使用手册

### 查看与编辑

1. 点击“新增条目”，填写标题和正文，点击“保存”。正文可以为空。
2. 点击列表中的标题查看条目。未解锁时输入主密码，一次解锁后可以连续查看和编辑。
3. 标题和正文均可修改，支持 `Ctrl+C`、`Ctrl+V`、`Ctrl+A` 和右键复制粘贴；`Ctrl+S` 保存修改。
4. 在搜索框输入标题的一部分筛选条目。选中条目后点击“删除条目”，确认后删除并保存。
5. 切换条目或关闭窗口时，如有未保存修改，会提示保存、放弃或取消。

正文按原样保存大小写、空格和换行。加载条目或恢复草稿后的正文作为撤销起点，撤销和重做只影响此后的编辑，不会撤销程序加载的正文或带出其他条目的文字。标题在文件中也是明文，敏感信息放在正文中。主密码无法找回，请自行保管。

### 锁定

点击“立即锁定”隐藏正文。在“设置”中调整闲置自动锁定时间：默认 5 分钟，范围 0～120 分钟，0 表示关闭。打开对话框不会无限暂停闲置锁定；锁定后未完成的导入比较需要重新开始。

设置、密码输入、导入比较、文件选择和确认窗口中的实际键鼠操作会刷新闲置时间；超时后关闭待处理窗口并遮蔽正文，重新解锁后再开始操作。文件选择沿用打开、保存及覆盖确认流程，使用可响应闲置锁定的中文窗口。

自动锁定会将未保存编辑加密暂存在内存，解锁后恢复，仍需保存；程序意外退出后暂存内容消失。存在锁定草稿时，关闭窗口可选择保存并退出、放弃并退出或取消退出：保存需要解锁，放弃无需输入密码且不改变已保存正文，取消则保留加密草稿和锁定状态。取消解锁、密码错误或保存失败时，程序不会退出，未保存修改仍保留。

如果草稿加密异常，程序先遮蔽正文并停止保险库访问，明确提示编辑尚未成功加密、仅保留在内存；重新输入主密码后可保存或放弃。关闭时仍可保存、放弃或取消，意外退出会丢失这些未保存编辑。

### 导出与另一台电脑导入

1. 勾选需要导出的条目。可用“勾选当前结果”和“清空勾选”批量操作；搜索不会清除已有勾选，状态文字显示总数。
2. 在“保险库”菜单选择“导出勾选条目”或“导出全部条目”，设置并确认至少 16 个字符的导出密码，保存为 `.lvexport` 文件。
3. 将文件传到另一台电脑，打开本地密匣，设置或解锁该电脑的主密码，选择“导入并合并”，输入导出密码。
4. 查看合并预览，处理冲突后点击“确认导入”。导入内容由当前电脑的主密码重新加密保存。

导出文件中的标题为明文、正文为密文。文件不绑定电脑或 Windows 账户，导出不会改变本地条目。

新版仍可用原密码读取旧保险库、旧导出和旧备份，包括旧版的 8 字符密码。新版创建的保险库、修改主密码后的保险库和新版导出使用加强的密码派生参数，`1.0.0` 无法读取；交换文件前请将两台电脑都升级到 `1.0.1` 或兼容版本。

| 合并情况 | 处理方式 |
| --- | --- |
| 导入标题和正文与最终保留内容完全相同 | 不重复添加 |
| 新条目 | 添加到本地 |
| 同一条目内容不同 | 选择保留本地、采用导入内容或两份都保留 |
| 不同条目标题相同、正文不同 | 提示可能重复，可保留本地或保留两份 |
| 本地条目没有出现在导入文件中 | 继续保留，不随导入删除 |

预览根据导入前的内容分类。确认导入时，程序结合全部冲突选择，按完整标题和正文精确去重，保留大小写、空格和换行差异。若同批覆盖使旧内容不再存在，预览中暂判重复的旧内容副本仍会补入；未被覆盖的本地条目保持原状。

### 备份、恢复与升级

在“保险库”菜单选择“完整加密备份”，生成 `.lvbackup` 文件；锁定状态下也可以备份。选择“从完整备份恢复”会**替换整个保险库**，恢复后使用备份创建时的主密码。导入用于合并条目，恢复用于替换整个保险库。

数据位于 `%LOCALAPPDATA%\LocalVault\vault.lvault`。新版默认只维护当前内容，保存、删除、导入、改密码和恢复均不再自动留下上一版文件；覆盖导出或手动备份也不增加 `.bak`。程序在内部先写加密临时文件，再替换当前文件，正常写入失败保留原文件，恢复来源始终保留。需要额外副本时，可以自行导出或选择完整加密备份。

新版不会清理旧版已经留下的 `.bak`、历史副本或用户主动保存的文件。修改主密码只影响当前保险库，不改变这些文件的密码；删除条目不代表对磁盘进行安全擦除。

运行新版安装包即可覆盖升级，安装和普通卸载均保留数据目录；手动备份是可选操作。仅安装新版不会加强旧库的派生参数，旧库在“修改主密码”中设置符合新规则的密码后才升级。长口令与加强参数提高猜测成本，仍需妥善保管主密码。

## 源码运行与构建

```powershell
py -3.12 -m venv .venv-build
.\.venv-build\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv-build\Scripts\python.exe -m local_vault
.\.venv-build\Scripts\python.exe -m pytest -q -k 'not plain_text_widget_preserves_text_and_save'
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
```

构建使用 PyInstaller 和 Inno Setup，输出到 `dist`。测试与构建默认跳过会改动系统剪贴板的一项测试；仅在专用测试环境中使用 `scripts/build.ps1 -IncludeClipboardTest`。推送 `v*` 版本标签会触发测试、构建、隔离安装验证与 GitHub 发布。公开仓库保存源码，安装包放在发布附件中；私人保险库和导出文件自行保管。
