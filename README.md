# 本地密匣

一个离线使用的 Windows 加密文本管理应用。每个条目只有标题和多行纯文本正文。标题直接显示，正文以主密码保护；密码、密钥、授权码和配置说明由你自由写入正文。

## 安装与首次设置

从 [GitHub 发布版本](https://github.com/YimingHao-Github/local-vault/releases/latest) 下载 `LocalVault-Setup-1.0.0.exe`，运行安装程序，再从开始菜单打开“本地密匣”。安装包含所需运行环境，不需要安装 Python。支持 Windows 10、Windows 11 的 64 位系统，默认按当前用户安装。

首次打开设置并确认主密码，至少 8 个字符。之后启动时只显示标题，点击条目查看正文时输入主密码；一次解锁可连续查看和编辑多个条目。忘记主密码无法恢复正文，请自行妥善保管。

## 日常使用

1. 点击“新增条目”，填写标题和正文，然后点击“保存”。正文可以为空。
2. 点击左侧标题查看或编辑条目；标题也可以直接修改。正文保留大小写、空格和换行，支持 `Ctrl+C`、`Ctrl+V`、`Ctrl+A`、右键复制与粘贴。`Ctrl+S` 可以保存。
3. 在搜索框输入标题的一部分，筛选左侧列表。
4. 选中条目后点击“删除条目”，确认后立即保存删除结果。
5. 切换条目、关闭窗口或执行需要处理当前编辑的操作时，若有未保存修改，会提示保存、放弃或取消。
6. 点击“立即锁定”清空显示中的正文。设置中可以选择闲置自动锁定时间，范围 0～120 分钟，默认 5 分钟；0 表示关闭。

自动锁定时，未保存编辑会加密暂存于内存，解锁后恢复，仍需点击“保存”。关闭程序前会提示处理这些编辑。意外终止程序或断电会丢失尚未保存的编辑。

## 加密导出与另一台电脑导入

左侧第一列可以勾选条目。搜索时勾选会保留，可用“勾选当前结果”和“清空勾选”批量操作。状态文字显示总勾选数量，包含搜索结果以外的勾选。

在“保险库”菜单选择“导出全部条目”或“导出勾选条目”，保存 `.lvexport` 文件，并设置、确认独立的导出密码。文件保留条目的内部唯一编号，不绑定电脑或 Windows 账户，导出不改变本地条目。导出文件的标题仍为明文，正文经过加密。

把文件手动传到另一台电脑，打开本地密匣，先设置或解锁该电脑的主密码，再选择“导入并合并”，选择文件并输入导出密码。程序校验完整性后显示新增、重复、编号冲突和可能重复的数量，以及本地和导入正文的只读比较。

- 标题与正文完全相同：只保留一份；即使编号不同也会去重，重复导入不会反复新增。
- 新编号、新内容：添加条目。
- 编号相同、内容不同：逐项选择“保留本地”“采用导入内容”或“两份都保留”。
- 标题相同、编号不同、正文不同：提示可能重复，默认两份都保留，也可以保留本地。
- 两份都保留：副本分配新编号。比较正文时不整理大小写、空格和换行。

最后点击“确认导入”，数据会使用当前电脑的主密码重新加密。导入文件中没有的本地条目继续保留。第一版不传播删除操作。取消导入、密码错误或文件损坏不会修改本地数据。

## 备份、恢复与升级

用户数据放在 `%LOCALAPPDATA%\LocalVault\vault.lvault`，与安装目录分开。请勿把此目录、备份或导出文件提交到公开仓库。

“完整加密备份”生成 `.lvbackup` 文件，包含全部条目及保险库设置；可以在锁定状态下备份。“从完整备份恢复”会校验密码和完整性后替换当前保险库，恢复后使用备份创建时的主密码。恢复前的原保险库保留为数据目录中的 `vault.lvault.bak`；需要时可在恢复文件对话框选择“所有文件”并恢复它。自动 `.bak` 只保留上一次保存版本，下次保存会更新，应另行保存重要备份。

在“保险库”菜单修改主密码，现有正文继续可读；已有备份和导出文件的密码不会改变。建议修改后重新制作完整备份。

升级时先备份，再直接运行新版安装程序。安装和卸载均保留数据目录，重新安装后继续使用原保险库。不要在保险库正在写入时手动覆盖数据文件。

## 源码运行与构建

```powershell
py -3.12 -m venv .venv-build
.\.venv-build\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv-build\Scripts\python.exe -m local_vault
.\.venv-build\Scripts\python.exe -m pytest -q
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
```

构建脚本使用 PyInstaller 打包程序、Inno Setup 制作安装程序，输出到 `dist`。固定依赖版本见 `requirements*.txt`。构建过程需要网络，安装后使用完全离线。加密采用 [cryptography 的 AES-GCM](https://cryptography.io/en/latest/hazmat/primitives/aead/) 与 [scrypt](https://cryptography.io/en/latest/hazmat/primitives/key-derivation-functions/#scrypt)；打包方式见 [PyInstaller 官方说明](https://www.pyinstaller.org/en/stable/usage.html)。

开发时可用 `--data-dir 路径` 隔离虚构测试数据。`--smoke-test --report 路径` 在临时目录执行加密与界面组件自测；`--version --report 路径` 查询版本。测试样本位于 `tests/fixtures/fake_entries.json`，全部为虚构内容，不预装进正式保险库。

发布 `v*` 标签会触发 Windows 自动化测试、安装包构建及 GitHub 发布。详细格式与保护范围见 [数据与安全说明](docs/数据与安全说明.md)，实际验证结果见 [验证记录](docs/验证记录.md)。
