本地密匣 1.0.0：离线使用的 Windows 加密文本管理应用。

下载 `LocalVault-Setup-1.0.0.exe` 安装即可使用，不需要安装 Python。标题直接显示，正文由主密码保护。支持标题搜索、多行纯文本、手动复制、明确保存、删除、手动与闲置锁定、修改主密码、多选加密导出、跨保险库导入去重与冲突选择、完整加密备份恢复。

已使用虚构数据通过 71 项自动化测试，并实际验证安装、模拟版本升级、正常启动与卸载后保留数据。用户数据保存在 `%LOCALAPPDATA%\LocalVault`，与程序文件分开。

安装包适用于 Windows 10、Windows 11 的 64 位系统，本机实际验证环境为 Windows 11；尚未在另一台物理电脑上安装。程序未配置代码签名证书，Windows 可能显示发布者未知。

同名 `.sha256` 文件提供安装包校验和。安装、导入、冲突处理、备份和升级操作见仓库的中文 `README.md`；验证细节见 `docs/验证记录.md`。
