界面测试实际使用 Tk 文本框和 Windows 系统剪贴板。检查发现本机 Tk 的 Python `clipboard_get()` 在长中文读取中存在分片异常；系统 Unicode 剪贴板及产品的标准粘贴路径完整正常，因此测试读取系统剪贴板验证，并保持产品标准编辑行为。

本机连续创建多个 Tk 根解释器时偶发出现组件初始化异常；产品每进程只创建一个根解释器。界面测试采用一个会话根解释器和各用例独立子窗口，并清理定时回调与全局绑定，完整回归通过。

## 程序与安装验证

- 实际生成包含 Python 与加密运行库的 Windows 程序，打包后的 `--smoke-test` 通过保存重开、加密导出导入、中文长文本和真实桌面文本框测试。
- 实际生成简体中文每用户安装包。安装包约 **11 MB**，无需安装开发环境。
- 在独立虚构资料目录实际安装，启动已安装的主窗口，保留虚构保险库。
- 使用同一应用标识，模拟安装版本从 1.0.0 升级到 1.0.1；升级前后保险库文件摘要一致，正文精确读取成功。
- 升级后的已安装程序自测通过，卸载后保险库仍存在且正文可读取。
- 实际截取主界面和导入合并窗口检查中文排版，增加了正文比较的横向与纵向滚动条。

安装升级验证脚本为 `scripts/test-installation.ps1`，仅使用 `.tools/installation-test` 下的虚构资料与测试安装路径，报告保存于 `build`。模拟的 1.0.1 只用于安装升级测试，正式源码及交付版本为 1.0.0。

## 验证范围

本机验证的是 Windows 11 64 位环境；尚未在另一台物理电脑或 Windows 10 上运行安装包。跨电脑流程通过独立保险库、不同主密码及不含电脑绑定信息的加密导出导入验证。程序与安装包未配置付费代码签名证书，Windows 可能显示发布者未知。密码学实现使用成熟库，本次完成了功能与异常测试，未进行独立的安全审计。

源码、固定依赖、构建和测试脚本进入公开仓库。私有保险库、导出、备份、开发环境和构建产物均由 `.gitignore` 排除；安装包及校验和在 GitHub 发布版本提供。
